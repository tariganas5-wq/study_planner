My Study Planner
This is a simple study planner app I am building using Flutter and Dart for my university project.
The app currently allows users to:
* View a list of study subjects and their hours.
* Add a new study goal.
* Mark a subject as completed.
* Delete a study goal.
Technologies Used
* Flutter
* Dart
Project Progress
* Phase 1: Basic screen design.
* Phase 2: Adding, completing, and deleting study goals.
Screenshots
Screenshots of the app are available in the screenshots folder.
How to Run
1. Clone this repository.
2. Run flutter pub get.
3. Run flutter run.
